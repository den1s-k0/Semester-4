## Лабораторная работа 7 & 8: Проектирование & реализация индивидуального проекта.

### Индивидуальное задание:
УЧЕТ ДЕНЕЖНЫХ СРЕДСТВ НА ВАЛЮТНОМ СЧЕТЕ

#### 1. Характеристика задачи  
Бухгалтерский учет операций в иностранной валюте должен обеспечивать, с одной стороны, отражение этих операций в качестве составной деятельности предприятия, с другой стороны, формировать обособленную картину о состоянии хозяйственных средств предприятия в иностранной валюте. Для реализации первого аспекта необходимо отражение всех валютных операций в едином денежном измерителе – базовой валюте (базовой валютой в Республике Беларусь являются белорусские рубли). Второй аспект предполагает необходимость ведения параллельного учета хозяйственных средств в реальных валютах. Это позволяет осуществлять полноценный контроль и анализ деятельности предприятия для принятия управленческих решений. 

Это означает, что все бухгалтерские записи должны производиться в рублях независимо от вида валют, фактически использовавшихся в хозяйственной операции. Рублевый эквивалент определяется путем пересчета сумм в иностранной валюте в рубли на основе валютного курса. Для реализации пересчета необходимо знать значение курса, по которому осуществляется перевод иностранной валюты на дату свершения операции. 

Курс иностранной валюты по отношению к рублю представляет собой выраженную в рублях цену других иностранных валют. В настоящее время в расчетах допускается использовать различные виды курсов. В практике расчетов используются курсы покупки–продажи валют коммерческих банков, аукционов, бирж. В бухгалтерском учете для пересчета иностранной валюты в рубли используется курс, определяемый Национальным банком Республики Беларусь. Данный курс является официальным курсом валюты. 

Официальный курс отличается от реальных коммерческих курсов, по которым совершаются хозяйственные операции. Поскольку в учете эти операции отражаются по официальному курсу, то в результате образуется суммовая разница, которая отражается отдельной бухгалтерской записью. 

Официальный курс валют подвержен колебаниям во времени, что обусловливает возникновение курсовых разниц. Курсовые разницы – это разницы в оценке валютных средств и обязательств, возникающие в период, связанный с проведением конкретной операции, из-за изменения официального курса рубля.

Таким образом, для эффективного контроля за состоянием валютных счетов необходимо автоматизировать учет поступлений и расходований валютных средств предприятий через валютные счета в банке. В данной задаче реализуем получение аналитической ведомости наличия валютных счетов в разрезе валют и отчета по курсовой разнице, образовавшейся у предприятия за некоторый период в белорусских рублях.

### Выходная информация
Выходной информацией для данной задачи являются документы:
1.	аналитическая ведомость наличия валютных средств в разрезе валют на некоторую дату;
2.	отчет по курсовой разнице, образовавшейся у предприятия при операциях с валютой за любой период.

Эти документы должны выводиться на экран и печать. Формы выходных документов приведены в формах 3.24 и 3.25.

**Форма 3.24.** Форма выходного отчета 1.
Аналитическая ведомость наличия валютных средств на __________ г.
|Валюта	|Наличие |По курсу Нац. банка, рублей |
|-------|--------|----------------------------|
|       |        |                            |
|Итого	|        |*                           |

**Форма 3.25.** Форма выходного отчета 2.
Отчет по курсовой разнице с __________ г. по __________ г.
Валюта __________.
|Дата  |Курс |Приход     |Приход |Расход     |Расход |Прибыль |Убыток |
|------|-----|-----------|-------|-----------|-------|--------|-------|
|      |     |Количество |Сумма  |Количество |Сумма  |        |       |
|      |     |           |       |           |       |        |       |	
|Итого |     |*          |*      |*          |*      |*       |*      |
|      |     |           |       |           |Сальдо |        |       |	

В первом отчете каждая операция с валютой представлена отдельной строкой. Во втором отчете любая операция разносится в одну из колонок: приход или расход. Для каждой операции подсчитывается прибыль или убыток, что также отражается только в одной графе. Прибыль образуется, если курс валюты, умноженный на количество, больше фактической суммы в белорусских рублях в приходе либо меньше суммы в расходе. В противном случае та же разница по абсолютной величине заносится в графу Убыток. В нижней строке отчетов подсчитываются итоговые суммы по колонкам, помеченным звездочкой. Под отчетом 2 окончательно выводится прибыльное или убыточное сальдо в зависимости от того, какая итоговая сумма больше.
